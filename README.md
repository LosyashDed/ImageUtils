# 🖼️ ImageUtil: Расширенный конвертер изображений

Простой, но мощный консольный инструмент для быстрой пакетной обработки изображений. Позволяет конвертировать форматы, изменять размер и отзеркаливать файлы без лишних усилий.

## ✨ Основные возможности
- **Конвертация форматов:** PNG, JPG, WEBP, GIF, TIFF.
- **Изменение размера:** Установка ширины и/или высоты с сохранением пропорций.
- **Отзеркаливание:** Горизонтальное и вертикальное отражение.
- **Пакетная обработка:** Обработка всех изображений в папке за один раз.
- **Умное именование:** Автоматическое добавление суффиксов к именам файлов (`_w800`, `_flip_h`).

## 🚀 Установка

**Требования:** Python 3.6+

**1. Клонируйте репозиторий**
```bash
git clone https://github.com/LosyashDed/ImageUtils.git
cd ImageUtils
```

**2. Установите зависимости**
Для работы скрипта необходима библиотека `Pillow`. Установите ее командой:
```bash
pip install -r requirements.txt
```

## 📖 Примеры использования

Поместите ваши изображения в папку `input_images/`. Результаты появятся в `output_images/`.

**1. Конвертировать все изображения в формат PNG**
```bash
python converter.py -t png
```

**2. Изменить ширину всех изображений до 800px, сохранив их исходный формат**
```bash
python converter.py --width 800
```

**3. Конвертировать в JPG, уменьшить ширину до 1024px и отзеркалить по горизонтали**
```bash
python converter.py -t jpg --width 1024 --flip-horizontal
```

**4. Запустить обработку, указав свои папки для исходников и результатов**
```bash
python converter.py -t webp --input-dir ./my_photos --output-dir ./processed_photos
```
